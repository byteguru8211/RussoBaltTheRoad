# Сетевая игра через RadminVPN

## Требования

- Два и более ПК в одной сети RadminVPN.
- На хосте разрешён входящий UDP-порт **7777** для игры.
- Одинаковая версия сборки у хоста и клиентов.

## Как играть

1. Хост открывает **Сетевая игра → Создать игру**.
2. Хост сообщает свой RadminVPN IP остальным игрокам.
3. Клиент открывает **Сетевая игра**, вводит IP хоста и нажимает **Подключиться**.
4. Все участники отмечаются **Готов**.
5. Хост нажимает **Начать гонку**.
6. Загружается зимний маршрут, машины расставляются на стартовой сетке.

## Ограничения текущей версии

- До 6 игроков.
- Прямое LAN-подключение без matchmaking и relay.
- Движение машин owner-authoritative; правила и лобби управляются хостом.
- Нет host migration: закрытие хоста завершает сессию.
- Сетевой режим использует зимную трассу как общий тестовый маршрут.

## Командная строка для тестов

```bash
RussoBaltTheRoad.exe -batchmode -nographics -lanhost
RussoBaltTheRoad.exe -batchmode -nographics -lanjoin 127.0.0.1
```

Для RadminVPN вместо `127.0.0.1` указывается IP хоста.

## Проверка

В финальной сборке отдельные host и client успешно подключились; в логах зафиксированы клиенты `0` и `1`, runtime-исключений нет.
