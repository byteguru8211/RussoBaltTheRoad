# Реализация игры в Unity

## Техническая база

- Unity 6000.6.10f1
- Universal Render Pipeline
- Input System 1.20.1
- C# / Mono2x
- Физика WheelCollider с фиксированным шагом
- Локальные JSON-сохранения профиля и настроек

## Игровой цикл

1. Главное меню → выбор экспедиции или гаража.
2. Гараж → выбор доступного автомобиля и маршрута.
3. Сюжетная открытка → отсчёт → гонка.
4. Checkpoint-контроль, круги, позиция, таймер.
5. Результаты → награда, рекорд, открытие следующей трассы.
6. Профиль хранит имя, пробег, победы, рубли, достижения и лучшие времена.

## Управление

| Действие | Клавиатура |
|---|---|
| Газ | W |
| Тормоз | S |
| Руль | A / D |
| Сцепление | Left Shift |
| Ручник | Space |
| Передачи | 1 / 2 / 3 |
| Задний ход | R |
| Ручной старт | F |
| Сброс машины | Backspace |
| Камера | C |
| Пауза | Escape |

Геймпад: левый стик — руль, правый/левый триггер — газ/тормоз, левый бампер — сцепление, D-pad — передачи, North — старт, East — сброс, правый стик — камера.

## Автомобили

- Russo-Balt C24/55: 1300 кг, RWD, 3 передачи, задние тормоза.
- Blitzen Benz: 1450 кг, RWD, цепная передача, 4 передачи в описании.
- Ford Model T: 544 кг, планетарная трансмиссия в описании.
- Fiat S76: 1650 кг, двойная цепь, очень высокий крутящий момент.
- Mercedes 37/90: 1950 кг, RWD, закрытая цепь.

В игре используется единый периодный контроллер с индивидуальными массами, моментами, колёсной базой и радиусом колёс. Точные исторические кривые момента требуют дальнейшей настройки.

## Трассы

- `winter_departure` — зимний выезд, 1 круг, 4 соперника.
- `alps_pass` — горный серпантин с изменением высоты, 1 круг, 5 соперников.
- `monaco_finish` — финальный маршрут, 2 круга, 6 соперников.

Трассы строятся из Catmull-Rom сплайна: дорожное полотно, бордюры, стартовая арка, контрольные точки, деревья/здания и земля.

## Системы

- `VehicleController1912` — руль, мотор, сцепление, тормоза, RPM, топливо, температура, повреждения, ремонт.
- `EngineAudio1912` — кроссфейд шести RPM-слоёв, гравий, ветер, ручной стартер.
- `AIDriver1912` — детерминированное движение по сплайну, профили скорости по поворотам, гоночная линия, ошибки по навыку и визуальное вращение колёс.
- `RaceManager` — отсчёт, checkpoint-логика, круги, позиция, награды, открытие маршрутов.
- `SaveSystem` — профиль и настройки в `Application.persistentDataPath`.
- `AchievementSystem` — семь достижений.
- `MainMenuUI`, `GarageUI`, `RaceHUD`, `PauseMenuUI`, `ResultsUI`, `StoryUI`, `SettingsUI`, `ArchiveUI`, `CreditsUI`.

## Проверка

- Компиляция Unity: 0 ошибок.
- Главное меню и гараж открываются без runtime-ошибок.
- Зимняя, альпийская и монакская трассы строятся и запускаются.
- Игрок разгоняется, рулит, проходит контрольные точки и получает результаты.
- AI движется по сплайну и не толкает игрока физическими коллайдерами.
- Награда и открытие следующей трассы сохраняются в профиль.
- Windows Release build запускается без исключений.

## Онлайн

Сетевой режим не включён в текущую сборку: для него нужны сервер/relay, аккаунты и отдельная сетевая физика. Локальные рекорды и достижения реализованы без внешних сервисов.
