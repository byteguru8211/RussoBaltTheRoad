## Ограничения

1. Это вертикальный срез production-архитектуры, а не завершённая AAA-игра.
2. LAN-режим реализован, но без matchmaking, relay, host migration и серверного античита; движение машин owner-authoritative.
3. Точные исторические кривые момента, торможения и сцепления требуют дополнительного баланса.
4. Оригинальный C24/55 не сохранился; часть размеров и ливреи являются реконструкцией.
5. Прямая загрузка главной фотографии C24/55 с Wikimedia ограничена HTTP 429; остальные PD/CC0-референсы сохранены локально.
6. В текущей партии один roadside-kit и три трассы; полный мир и кампания ещё предстоят.
